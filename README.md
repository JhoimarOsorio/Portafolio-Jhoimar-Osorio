# Portafolio-Jhoimar-Osorio

Portafolio personal y responsive de Jhoimar Osorio. Reúne proyectos de desarrollo web y actividades de programación en una página estática construida con HTML, CSS y Bootstrap 5.

## Proyectos

- **Rueda Libre:** sitio informativo de alquiler de bicicletas y campaña Rueda Nocturna. [Ver sitio](https://jhoimarosorio.github.io/rueda-libre/) · [Repositorio](https://github.com/JhoimarOsorio/rueda-libre)
- **Actividades de la clase de IA:** ejercicios de algoritmos y una página web creada con herramientas de inteligencia artificial. [Repositorio](https://github.com/JhoimarOsorio/Portafolio-sesion-1)
- **Algoritmia 1:** prácticas de lógica, tablas de decisión y pruebas de escritorio. [Repositorio](https://github.com/JhoimarOsorio/Algoriitmia-1)

## Tecnologías y componentes

- HTML5, CSS3 y Bootstrap 5.3.3.
- Navbar colapsable para móvil y grilla responsive.
- Tarjetas de proyecto, botones e iconos de Bootstrap.
- Bootstrap Icons y Google Fonts cargados desde CDN.

## Ejecutar localmente

Abre `index.html` en un navegador con conexión a internet para cargar Bootstrap, los iconos y las fuentes externas.

## Publicación

GitHub Actions despliega el sitio en GitHub Pages cuando hay cambios en la rama `main`.

**Sitio:** [https://jhoimarosorio.github.io/Portafolio-Jhoimar-Osorio/](https://jhoimarosorio.github.io/Portafolio-Jhoimar-Osorio/)

La primera publicación puede tardar unos minutos. Si GitHub Pages aún no está habilitado para el repositorio, ve a **Settings → Pages** y selecciona **GitHub Actions** como fuente.
